# Powerhouse Casting V2 — candidature uniquement

La V1 est conservée dans ../powerhouse-v1-backup/site et dans le pack V1 d’origine. Cette V2 n’est pas destinée aux portfolios publics : une version neutralisée devra être préparée et validée séparément.

Lancement : depuis ce dossier, python -m http.server 8795 --bind 127.0.0.1 puis ouvrir http://127.0.0.1:8795/. Éditeur local : /admin/. Aucun serveur applicatif, abonnement ou compte n’est nécessaire pour la simulation. Les vidéos Vimeo nécessitent Internet.

Sources : assets/data.json (contenus initiaux), assets/layouts.json (sections et champs des six pages), assets/model.js (validation), assets/content-store.js (persistance locale), assets/renderer.js (prévisualisation), assets/site.js et site.css (interactions et présentation), admin/ (interface éditoriale). Les originaux photo sont conservés ; studio-grade.svg applique les corrections réversibles. Les sauvegardes de l’éditeur sont exportables en JSON et ne modifient jamais les fichiers source.

Dossier client : reports/delivery.html. Comparatifs : reports/photo-review.html. Vidéo anglaise : training/index.html et training/editor-walkthrough.mp4. Les imports CMS sont dans framer-import/ ; les associations sont à configurer dans le véritable projet Framer.

Une simulation locale n’est pas le CMS Framer. Le prototype Framer natif reste à créer après connexion au compte ; aucun template n’a été acheté. La vidéo définitive sera enregistrée dans le projet Framer livré.

Tests complémentaires confiés à un autre agent à la demande du propriétaire : reports/TEST-HANDOFF.html. La passe finale est volontairement interrompue ; ne pas présenter le rapport comme une certification complète.

Le lien de candidature utilise un chemin aléatoire non répertorié et noindex. Toute personne qui possède ce lien peut le consulter. Ce n’est pas une authentification nominative et aucun lien n’est ajouté aux portfolios. Les droits de diffusion publique des médias restent à valider avant une version publique.
